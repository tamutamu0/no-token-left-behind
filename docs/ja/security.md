# 安全性と制約

この仕組みは、自分のアカウントの利用状況を自分の端末で見るためのものです。設計の方針と、守れること・守れないことをまとめます。

脆弱性の報告は [SECURITY.md](../../SECURITY.md) を参照してください。

## 認証情報

- 各サービスへの問い合わせは、利用者がログインした**公式 CLI** に任せます。自作のコードがパスワード、Cookie、OAuth トークンを読み出したり、保存したり、別の場所へ渡したりすることはありません。
- Claude・Antigravity の CLI 起動には第三者ツールの CodexBar を使います。専用の一時設定で取得元を CLI に固定し、Cookie の取得や拡張機能は無効にしています。取得元が CLI 以外の応答は捨てます。
- Codex の app-server に送るのは `initialize`、`initialized`、`account/rateLimits/read` だけです。スレッドの開始、メッセージ送信、購入、枠のリセットを送る経路はありません。
- Colab は公式 CLI の `usage` だけを実行します。ただし、公式 CLI 自体が初回に要求する OAuth の権限は残量の読み取りより広い場合があります。認可画面で内容を確認してください。

公式 CLI と CodexBar は、それぞれの入手元を利用者が信頼する前提です。

## iCloud に出るデータ

iCloud Drive の利用者が選んだフォルダに、`ai-usage-snapshot-v2.json` を 1 つだけ書きます。中身は次の項目に限られます。

- 固定のサービス ID と取得元の種類
- 残り %（使用率）、回復時刻、残高
- 観測時刻、Colab の付与を観測した時刻、確認済みの総量
- スキーマの版とデモかどうか

アカウント名、メールアドレス、会話、CLI の生の出力、エラーメッセージは含めません。受け取った JSON に余分な項目があっても、検証済みのモデルに再エンコードする段階で捨てます。

残量の値は Apple の iCloud に保存されます。Apple アカウントが侵害されれば利用状況を読まれる可能性があるため、共有フォルダを出力先にしないでください。

ファイルは署名されていません。iCloud のそのフォルダに書き込める相手が嘘の値を置くことまでは防げません。

## Mac の中だけに置くデータ

`~/Library/Application Support/AIUsage/`（フォルダの権限は 0700、ファイルは 0600）：

| ファイル | 中身 |
|---|---|
| `snapshot.json` | 最新の取得結果（同期ファイルと同じ項目） |
| `colab-history.json` | Colab の残高・消費ペース・稼働数・観測時刻（90 日分） |
| `colab-grants.json` | 観測した Colab の付与（前後の時刻と残高、最新 36 件） |
| `colab-allocation.json` | 利用者が確認した Colab の総量（任意） |
| `collector-health.json` | 取得処理の時刻と成否、同期のエラーコード |

これらは iCloud にも Git にも出しません。リポジトリの `.gitignore` でも実データ・鍵・接続ファイルを除外しています。

## Scriptable のスクリプト

- 通信の API（`Request` など）を使いません。iCloud のファイルを読むだけです。
- スキーマ、サービス ID、取得元、数値の範囲、観測時刻、ファイルサイズを検証してから使います。許可した項目だけを Scriptable のローカルにキャッシュします。
- 壊れたファイルやデモのファイルで、検証済みの実データのキャッシュを上書きしません。

## `doctor.py`

自己診断は読み取り専用です。CLI の場所を探し、ログイン情報のファイルは中身を読まずに存在だけを確かめ、`collector-health.json` と同期ファイルの経過時間を読み、アプリとログイン項目が入っているかを確かめます。サービスへの問い合わせはせず、秘密の値も表示しません。

## Mac アプリの署名

`Scripts/install_mac_startup.py` は、更新のたびに iCloud フォルダの選び直しが要らないよう、このMac専用の署名用の鍵を作ります。

- 鍵は専用のキーチェーンに保存し、取り出し不可にします。キーチェーンの利用は `codesign` に限ります。
- 署名の条件はアプリ ID と証明書の指紋の両方で、別の署名のアプリを同じアプリとは扱いません。
- システムの信頼設定、TCC、Gatekeeper は変更しません。キーチェーンの検索順は署名後に元へ戻します。
- 署名用の鍵を Git や iCloud に入れません。

## プレビュー

Mac アプリのウィジェットのプレビューは、保存しない WebKit に同梱の描画コードと検証済みの数値だけを渡して描きます。CSP で通信・画像・フレームを禁止し、ページ遷移も拒否します。

## ネイティブ版の直接接続

- Apple Network.framework の TLS-PSK（TLS 1.2 / PSK-AES-128-GCM-SHA256）で暗号化と相互確認をします。32 バイトのランダムな鍵を CryptoKit で作ります。平文への切り替えはありません。
- Mac は指定したプライベート IP（10/8、172.16/12、192.168/16、Tailscale の 100.64/10）だけで待ち受け、公開 IP やホスト名への接続は拒否します。
- PSK 方式なので前方秘匿性はありません。鍵が漏れたら Mac で鍵を無効にして、ペアリングし直してください。
- 接続ファイルには鍵が入っています。自分の iPhone だけに渡し、Git・チャット・共有ドライブに置かないでください。

## 制約

- Mac アプリは公式 CLI を起動するため、App Sandbox を有効にしていません。OS がアクセス範囲を強制する構成ではなく、小さく公開された実装の範囲に依存しています。
- 第三者によるセキュリティ監査は受けていません。
- 端末そのものが侵害された場合や、アプリが改変された場合は守れません。
